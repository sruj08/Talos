## 3. Evaluation Criteria & Tie-Breaking Hierarchy (Official Rules §6)

### Stage 1: Pass/Fail Baseline Gate (Devpost Screening)
1. Working software prototype built during the Submission Period.
2. Substantive use of PayPal APIs / AI developer tools in PayPal Sandbox.
3. Public YouTube demo video under 3 minutes (`< 3:00`).
4. Public GitHub repository with an open-source `LICENSE` file **visibly detected in the top "About" section**.

### Stage 2: Jury Evaluation (100 Points Total — Tie-Break in Exact Listed Order)
1. **Technological Implementation (20% — Tie-Breaker #1)**: Quality of code, depth of PayPal + AI integration (`@paypal/agent-toolkit`, PayPal MCP, `@paypal/paypal-server-sdk`, JS SDK v6), reliability, and partner tool integration.
2. **Design (20% — Tie-Breaker #2)**: User experience, visual craft, information hierarchy, and interactive responsiveness (AG Grid / AG Studio / Bryntum UI polish).
3. **Potential Impact (20% — Tie-Breaker #3)**: Real-world utility, market size, economic/social value, and readiness for merchant or consumer adoption.
4. **Innovation / Idea (20% — Tie-Breaker #4)**: Originality, non-obvious insight, and departure from generic chatbot wrappers.
5. **Presentation (20% — Tie-Breaker #5)**: Clarity of the <3-minute YouTube video, live end-to-end Sandbox flow, and README architecture documentation.

## 4. Suggested Domains / Tracks (Verbatim Mapping)
- **D1 — AI Agents & Agentic Commerce**: Autonomous discovery, negotiation, A2A payments, MCP toolchains, and policy-guarded execution.
- **D2 — Money Movement Experiences**: Peer-to-peer transfers, group settlement, cross-border payouts, and programmable disbursements.
- **D3 — Business Solutions**: Merchant operations, dispute representment, milestone invoicing/escrow, subscription lifecycle, and B2B workflows.
- **D4 — Consumer Experiences**: Smart shopping assistants, price/scam protection, BNPL (Pay Later), and personalized checkout.
- **D5 — Social Impact Ideas**: Transparent philanthropy, climate/community co-ops, accessible voice commerce, and disaster relief payouts.
