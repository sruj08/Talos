# Phase 08 Plan 01 (Micro-Chunk 8.1): Render Native Polyglot Blueprint (`render.yaml`) Deployment & Live Webhook Verification

## Objective
Harden and validate the 1-Click Render Native Polyglot Blueprint (`render.yaml`) across all 5 resources (`talos-firewall-rs` `runtime: rust`, `talos-orchestrator-go` `runtime: go`, `talos-console-web` `runtime: node`, `talos-valkey` `type: keyvalue`, and `talos-postgres` `postgresMajorVersion: "16"`), implement Next.js `/api/healthz` and `/healthz` readiness endpoints, ensure Render `PORT` and `fromService` environment variable resolution across Rust and Go, and verify end-to-end `/healthz` + PayPal Webhook CRC32/RSA verification (`API-04` & `API-14`) via `scripts/verify-deployment.sh` and `scripts/verify-deployment.ps1`.

## Tasks

### Task 1: Render Native Polyglot Blueprint (`render.yaml`) & Service Port/Discovery Hardening
- Harden `render.yaml` with `plan: starter`, `region: oregon`, `healthCheckPath: /healthz` (`talos-firewall-rs` & `talos-orchestrator-go`), `healthCheckPath: /api/healthz` (`talos-console-web`), `PORT` + service-specific port variables, `fromService` (`RENDER_EXTERNAL_URL` + `connectionString`), `fromDatabase` (`connectionString`), and all `sync: false` secrets.
- Update `services/firewall-rs/src/main.rs` (`resolve_listen_port()`) and `services/orchestrator-go/cmd/server/main.go` (`resolveListenPort()`) to prioritize Render's `PORT` environment variable and bind to `0.0.0.0`.
- Add `NormalizeServiceURL()` and `ResolveFirewallURL()` in `services/orchestrator-go/internal/handlers/escrow_handlers.go` supporting both `RUST_FIREWALL_URL` and `FIREWALL_RS_INTERNAL_URL`.

### Task 2: Next.js 15 Readiness Probes (`/api/healthz` & `/healthz`)
- Implement `web/src/app/api/healthz/route.ts` and `web/src/app/healthz/route.ts` returning `200 OK` JSON (`{ service: "talos-console-web", status: "ok", ... }`) with `Cache-Control: no-store`.
- Add Vitest unit tests in `web/src/app/api/healthz/route.spec.ts`.

### Task 3: Deployment & Webhook Verification Harness (`scripts/verify-deployment.sh` & `scripts/verify-deployment.ps1`)
- Enhance `scripts/verify-deployment.sh` and `scripts/verify-deployment.ps1` to validate all 5 `render.yaml` resources, probe `/healthz` across all 3 services, and execute live PayPal Webhook CRC32 + RSA/Ed25519 signature verification against `POST /v1/firewall/webhook/verify` (`API-04`) and `POST /api/v1/webhooks/paypal` (`API-14`).
