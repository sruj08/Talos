## Reporting a Vulnerability
- Do not open public GitHub issues for cryptographic or prompt-injection bypass vulnerabilities.
- Report via private security advisory or email `security@talos.dev`. Response SLA: `<6 hours` (aligned with CERT-In guidelines).
