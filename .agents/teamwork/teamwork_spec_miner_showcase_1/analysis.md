   - **Pillar 3 — Channel3 Fair-Price Oracle (Market Price Check)**: Every product offer is verified against `100M+` real-time SKUs via Channel3; if a store marks up a `$249.00` SSD to `$480.00` (`+92.7%` gouge), TALOS blocks the store and reroutes the agent to a verified merchant at `$249.00` (saving `$231.00`).
   - **Pillar 4 — PayPal Escrow Hold (`AUTHORIZE` -> Tracking -> `CAPTURE`/`VOID`)**: Instead of handing over money irreversibly at checkout, TALOS places a reversible **29-day PayPal `Orders v2 AUTHORIZE` hold**. Funds are released (`CAPTURE`) only when FedEx/DHL confirms `DELIVERED`, or automatically refunded (`0s VOID`) if the 48-hour delivery SLA is breached.
3. **Prominent CTA & Navigation**:
   - Prominent **Try Interactive Demo** CTA button (`data-testid="landing-try-demo-cta"`) that launches/scrolls smoothly to the Interactive Manipulation Simulator & Command Center and triggers/highlights the live flow.
