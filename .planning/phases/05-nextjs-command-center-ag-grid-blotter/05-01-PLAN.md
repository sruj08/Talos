# Phase 05 Plan 01 (`TASK-09`): Next.js 15 Command Center Shell, KYA Mandate Studio & Live WebSocket Store

## Optimized Execution Prompt
> Build the TALOS `web/` Command Center against the real Phase 1–4 wire contracts (`handlers.EscrowEntry`, `ws.Event`,
> `firewall-rs KyaMandate`). No Tailwind dependency: ship a token-based `globals.css` from `DESIGN_SYSTEM.md`.
> Every network path must degrade to the deterministic Sandbox Replay Fallback so judges can demo offline.
> Keep pure logic in `src/lib/*` (unit-testable) and keep each file under 250 lines.

## Tasks
1. **Contracts & config** — `lib/types.ts` mirrors orchestrator + firewall JSON; `lib/config.ts` reads only public `NEXT_PUBLIC_*` URLs.
2. **API client** — `lib/api.ts` with timeouts, RFC 7807 error mapping, and a fresh `PayPal-Request-Id` on every capture / void / dispute.
3. **Mandate crypto** — `lib/mandateCrypto.ts` reproduces `canonical_mandate_digest` (sorted keys, compact JSON, SHA-256) and Ed25519 sign/verify via WebCrypto.
4. **Live store** — `lib/escrowStore.ts` (`normalizeRow`, `applyEvent`, `diffRows`, `computeKpis`) + `hooks/useEscrowStream.ts`.
5. **Sandbox Replay** — `lib/escrowSim.ts` seeded PRNG rows + WS-shaped `ESCROW_STATE_TRANSITION` frames.
6. **Shell** — `CommandCenter.tsx`, `KpiHeader.tsx`, `StatusBadge.tsx`, `MandateStudio.tsx`, `layout.tsx`, `page.tsx`, `globals.css`.
