# Phase 2 Plan 02 (`TASK-04`): Rust `lol_html` + `DeBERTa-v3` ONNX Prompt-Injection Sanitizer & `rmcp` MCP Server

## Objective
Implement the streaming `lol_html` + `aho-corasick` + `M-01` `DeBERTa-v3` INT8 ONNX classifier pipeline in `services/firewall-rs/src/sanitizer.rs` (`< 250` lines) and the JSON-RPC 2.0 MCP server in `services/firewall-rs/src/mcp_server.rs` (`< 250` lines), wired into `services/firewall-rs/src/main.rs` (`< 250` lines).

## Tasks
1. **Upgrade `services/firewall-rs/src/sanitizer.rs` (< 250 lines)**:
   - Use `lol_html::{rewrite_str, element, comments, RewriteStrSettings}` to stream-strip hidden elements (`display:none`, `display: none`, `opacity:0`, `opacity: 0`, `visibility:hidden`, `visibility: hidden`, `font-size:0`, `font-size: 0`, `hidden`, `aria-hidden="true"`, `<script>`, `<template>`) and HTML comments (`<!-- ... -->`).
