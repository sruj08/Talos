# Phase 07 Plan 01 (Micro-Chunk 7.1): Elastic Cloud OpenTelemetry APM, Vector Threat Index & Postman MCP Collection

## Objective
Implement distributed OpenTelemetry trace instrumentation (`W3C traceparent`) across the Go 2PC Escrow Orchestrator (`talos-orchestrator-go`) and the Rust Security Firewall (`talos-firewall-rs`), wire live Elastic Cloud APM OTLP trace export and Elasticsearch kNN Threat Vector Indexing (`talos-dom-threats-v1`), and build the 1-Click Judge Verification Postman Collection (`postman/Talos-Sandbox-MCP.postman_collection.json`) and Environment (`postman/Talos-Sandbox.postman_environment.json`) covering `API-01` through `API-16`.

## Tasks

### Task 1: Rust Firewall OpenTelemetry Span Recorder (`services/firewall-rs/src/otel.rs`)
- Implement W3C `traceparent` parser/generator (`parse_or_generate_traceparent`) and Axum middleware (`otel_trace_middleware`).
- Record `rust_firewall.verify_mandate` (`kya.ed25519.verified`, `kya.rfc9421.key_id`, `kya.latency_us`, `talos.mandate.id`) and `rust_firewall.sanitize_dom` (`dom.lol_html.stripped_nodes`, `dom.deberta.risk_score`, `dom.verdict`, `talos.firewall.risk_score`).
- Expose `GET /v1/telemetry/spans` and verify unit tests.

### Task 2: Go Orchestrator Elastic Cloud OTLP Exporter & Vector Threat Index (`services/orchestrator-go/internal/telemetry/`)
- Implement `TelemetryEngine` in `elastic_otel.go` and `elastic_exporter.go` (<250 lines each).
- Enforce DPDP 2023 & PCI-DSS v4.0 PII redaction (`RedactEmail`, `RedactBearer`) before span or vector export.
- Attach required span attributes (`talos.mandate.id`, `talos.firewall.risk_score`, `talos.channel3.spread_bps`, `paypal.order_id`, `paypal.auth_id`).
- Compute 64-bit SimHash (`simhash_signature`) and 16-dimensional L2-normalized semantic threat vectors for `talos-dom-threats-v1` with `<20ms` cosine kNN lookup and live Elastic Cloud indexing using `.env` credentials without secret leaks.

### Task 3: Postman MCP & PayPal Sandbox Collection (`postman/`)
- Build `postman/Talos-Sandbox-MCP.postman_collection.json` and `postman/Talos-Sandbox.postman_environment.json` covering all 3 folders (`01 — Rust Zero-Trust Firewall`, `02 — Go Orchestrator, Channel3 Oracle & PayPal Sandbox Escrow`, `03 — Blotter, Bryntum Gantt, Webhooks, Audit Chain & MCP Bridge`) with Newman `pm.test()` scripts and `traceparent` propagation.
