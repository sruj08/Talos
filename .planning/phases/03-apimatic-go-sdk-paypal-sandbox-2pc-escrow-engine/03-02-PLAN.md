# Plan 03-02: Two-Phase Commit (2PC) Escrow State Machine (`TASK-06`)

## Objective
Implement the deterministic Two-Phase Commit (2PC) Escrow State Machine in Go (`services/orchestrator-go/internal/escrow/machine.go`, `internal/escrow/handlers.go`, and `services/orchestrator-go/internal/paypal/service.go`) binding KYA mandates to PayPal Sandbox `Orders v2 AUTHORIZE`, `Authorizations CAPTURE`, and `Authorizations VOID` with `PayPal-Request-Id` idempotency locks and cached response replay.

## Tasks
1. **Wire SDK dependency in `services/orchestrator-go/go.mod`**:
   - Add `require github.com/talos/sdk/paypal-go-apimatic v0.0.0` (mapped to `../../sdk/paypal-go-apimatic`).
2. **Implement `services/orchestrator-go/internal/paypal/service.go` (`< 250` lines) & `service_test.go`**:
   - Wrap `paypalapimatic.Client` in `SandboxService` with `NewSandboxService`, `NewSandboxServiceFromEnv`, `AuthorizeEscrowHold`, `CaptureEscrowHold`, `VoidEscrowHold`, `AttachTracking`, and `SubmitDisputeEvidence`.
3. **Implement `services/orchestrator-go/internal/escrow/machine.go` (`< 250` lines)**:
   - Define full 2PC state graph (`INITIATED`, `MANDATE_VERIFIED`, `CHANNEL3_BENCHMARKED`, `BLOCKED_FIREWALL`, `BLOCKED_PRICE_GOUGING`, `STEP_UP_REQUIRED`, `PAYPAL_AUTHORIZED`, `SLA_SCHEDULED`, `TRACKING_VERIFIED`, `PAYPAL_CAPTURED`, `PAYPAL_VOIDED`, `DISPUTE_FILED`, `DISPUTE_EVIDENCE_SUBMITTED`).
   - Implement `Engine` with pessimistic per-escrow locking, `PayPal-Request-Id` idempotency locking (`AcquireIdempotencyLock`) + cached response replay for duplicate `PayPal-Request-Id` calls, and methods `AuthorizeEscrow`, `CaptureEscrow`, `VoidEscrow`, `AdvanceState`, and `FileDispute`.
4. **Implement `services/orchestrator-go/internal/escrow/handlers.go` (`< 250` lines) & wire `cmd/server/main.go`**:
   - Expose `API-07` (`POST /api/v1/escrow/{id}/authorize` and `POST /api/v1/escrow/authorize`), `API-09` (`POST /api/v1/escrow/{id}/capture`), and `API-10` (`POST /api/v1/escrow/{id}/void`).
5. **Verify (`internal/escrow/machine_test.go` & `internal/paypal/service_test.go`)**:
   - Run all unit, concurrency, idempotency, and illegal-transition tests across `services/orchestrator-go`.
