# Phase 04 Plan 02 (`TASK-08`): Unified Checkout Fan-Out (`API-05`), PayPal Tracking (`API-08`), Disputes (`API-11`), Blotter/SLA (`API-12`/`API-13`) & WebSocket Event Hub (`API-15`)

## Tasks
1. **Implement Concurrency-Safe RFC 6455 WebSocket Hub (`services/orchestrator-go/internal/ws/hub.go` & `hub_test.go`)**:
   - Implement zero-external-dependency RFC 6455 WebSocket handshake (`Sec-WebSocket-Key` -> `Sec-WebSocket-Accept` SHA-1 + Base64) and server-to-client text frame writer using `http.Hijacker`.
   - Implement thread-safe client registration, unregistration, bounded history replay buffer, and non-blocking `Broadcast(evt)` of `ESCROW_STATE_TRANSITION` payloads.
2. **Implement Unified Handlers (`services/orchestrator-go/internal/handlers/`)**:
   - `api.go`: Server struct, route registration (`API-05` through `API-15`), `POST /api/v1/channel3/benchmark` (`API-06`), `POST /api/v1/escrow/{id}/tracking` (`API-08`), and `POST /api/v1/escrow/{id}/dispute-evidence` (`API-11`).
   - `checkout.go`: Parallel fan-out pipeline for `POST /api/v1/checkout/evaluate` (`API-05`) combining KERNEL DOM inspection, Rust Firewall KYA mandate + DOM sanitization (live HTTP + in-process deterministic fallback), Channel3 price oracle, step-up threshold check (`$300.00`), and PayPal `Orders v2 AUTHORIZE`.
   - `sla_blotter.go`: `GET /api/v1/escrow/blotter` (`API-12`), `GET /api/v1/sla/timeline` & `PATCH /api/v1/sla/timeline/{task_id}` (`API-13`, triggering `VoidHold` on `SLA_BREACHED`), and `POST /api/v1/webhooks/paypal` (`API-14`).
3. **Wire Orchestrator Entrypoint (`services/orchestrator-go/cmd/server/main.go`)**:
   - Instantiate `store.Store`, `paypal.SandboxService`, `escrow.Engine`, `channel3.Oracle`, `kernel.Inspector`, `ws.Hub`, and `handlers.Server`, exposing all `API-05`..`API-15` routes on `:8080`.
4. **Implement Comprehensive Handler & E2E Flow Tests (`services/orchestrator-go/internal/handlers/api_test.go`)**:
   - Test all 3 Golden Flows + Dispute Flow + SLA Breach Flow + WebSocket Event Broadcast:
     - Flow 1: Poisoned Storefront blocked (`422 TALOS_DOM_PROMPT_INJECTION_BLOCKED`).
     - Flow 2: `$480` Shure SM7B price-gouging blocked (`422 TALOS_CHANNEL3_PRICE_GOUGING`) and auto-rerouted (`auto_reroute: true` -> `$249` `PAYPAL_AUTHORIZED` -> `TRACKING_VERIFIED` + `DELIVERED` -> `PAYPAL_CAPTURED`).
     - Flow 3: SLA Breach via `PATCH /api/v1/sla/timeline/{task_id}` -> `PAYPAL_VOIDED`.
     - Flow 4: Dispute Evidence via `POST /api/v1/escrow/{id}/dispute-evidence` -> `201 Created` (`DISPUTE_EVIDENCE_SUBMITTED`).
     - Step-up approval (`$450` > `$300` -> `202 Accepted` `STEP_UP_REQUIRED`).
